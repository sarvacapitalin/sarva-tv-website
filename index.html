Engineering Blueprint

Modern Android Architecture

Built adhering to strict Modern Android Development (MAD) mandates and Unidirectional Data Flow (UDF) patterns.

Kotlin 2.x & Sealed State Flow

MAD Paradigm

100% written in idiomatic Kotlin with coroutine structured concurrency. Encapsulates UI states inside immutable data classes exposed via read-only StateFlow to guarantee zero race conditions.

Room Diffing & Threshold Safeguards

Database Ops

Uses Room Database with diff-based transaction updates to preserve flash memory lifespan. Capping protection thresholds set at 3,000 channels for Smart TV RAM constraints and 30,000 channels for high-spec mobile hardware.

Play Integrity & Security Hashing

Anti-Tamper

Integrates Google Play Integrity API with cryptographic SHA-256 token binding via Cloudflare Workers and Firebase Cloud Functions to verify client authenticity and protect against unauthorized tampering.

Per-Channel Headers & LCN EPG

Stream Customization

Full support for custom HTTP User-Agent headers, Logical Channel Numbers (`tvg-chno`), custom XMLTV guide integration, and MD5 stream URL deduplication.
